## Setup and observed costs

One dedicated PostgreSQL 17.11 server served 48 isolated databases, with fixed
1 CPU / 512 MiB allocation and `synchronous_commit=off`. SQLite selected
Disposable/WAL/OFF. Construction used `LAYERFS_CONSTRUCTION_WORKERS=1`.
Machines, binaries, images and the PostgreSQL instance were reused between rows;
writable Stores and database history were isolated per row and consumed once.

The 36 guest SQLite preparations each pushed a 212,992-byte initialized Store
(208 KiB), totaling 7,667,712 bytes. C09–C11 built and committed their 64 MiB base
on the destination, then closed the preparation Sandbox. Ready case execution
required no Store push. PostgreSQL inputs were attached directly, with no file
transfer. Server disposal removed all database data at finish.
